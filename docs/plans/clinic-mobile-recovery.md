# Clinic mobile recovery implementation plan

Goal: restore an actionable path from saved pictures to supported 3D without redesign or overriding initial accessibility preferences.
Architecture: App owns explicit static/3D choice, a compact typed failure stage and at most two manual recovery attempts per page. Capability checks require WebGL2 (Three r182), release temporary probe contexts and recheck on user retry. Experience reports renderer/context errors; AcceptedClinic reports load/timeout errors. StaticJourney preserves every story section and forms, exposes opt-in/retry controls and plain local diagnostics. No telemetry or persisted override.
Tech: existing React 19, Three r182, R3F, Vite, existing Playwright install (no new runtime dependencies).

1. Baseline (before source changes): run `node scripts/clinic-mobile-recovery.mjs`. Capture mobile Chromium and WebKit normal render, reduced-motion, forced static, injected asset failure, WebGL2 unavailable (WebGL1 still allowed) and actual WEBGL_lose_context. Record errors, request failures, render cost and before screenshots. Root cause candidates ranked: preference/static dead end; asset/runtime dead end; WebGL1 false-positive/context probe resource leak; physical GPU pressure (not established by desktop emulation).
2. Preference recovery vertical slice: RED assertion for explicit enable-3d; App and StaticJourney add explicit static labeling, scroll-motion warning and opt-in; retain return-to-static action. Run reduced/static cases GREEN before next slice.
3. Runtime recovery vertical slice: RED missing retry/assert wrong stage; type errors in src/lib/sceneFailure.ts, thread callback through JourneySection/Experience/AcceptedClinic. Keep two manual low-quality attempts, never automatic retries. WebGL2 probe rechecks and releases its context; failure never forces unsupported Canvas. Re-run injected failures GREEN. Do not change assets, animation or rendering budgets without evidence.
4. Verification: extend browser checks for exhausted attempts, retained seven story sections/contact/forms, return-to-static, capability recovery and failure stages. Run Chromium + available WebKit forward/reverse actual bones and patient transforms at 375/390, overhead visibility, desktop and production no-diagnostic smoke. Existing motion/asset/wall tests, lint/typecheck/build/pages build. All logs/images under ignored docs/evidence/mobile-recovery.
5. Handoff: docs/mobile-recovery-handoff.md with exact commands/results, confidence limits, selectors, engine versions, production release contract and rollback 29abb80561fa85ffb4e02b6affeaa38dd3e93313. Stop owned servers; no commit/push. Complete parent to release existing publisher t_51600dec.
